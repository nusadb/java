# nusadb-hibernate5: Hibernate ORM 5.x dialect for NusaDB

A thin [Hibernate ORM](https://hibernate.org/) 5.x dialect layered on the
[`nusadb-jdbc`](../README.md) driver, for Spring Boot 2.x applications and others on
`javax.persistence`. Built and tested against Hibernate **5.6.14.Final** (and 5.6.15, the version
of Spring Boot 2.7) and Java 17. For Hibernate 6.x use [`../hibernate6`](../hibernate6) instead.

## Usage

```properties
hibernate.dialect                 = com.nusadb.hibernate.NusaDialect
hibernate.connection.driver_class = com.nusadb.jdbc.NusaDriver
hibernate.connection.url          = jdbc:nusadb://user@host:5678/nusa
```

In Spring Boot 2.x:

```properties
spring.datasource.url=jdbc:nusadb://db.internal:5678/app
spring.datasource.driver-class-name=com.nusadb.jdbc.NusaDriver
spring.jpa.database-platform=com.nusadb.hibernate.NusaDialect
```

What the dialect does:

- **Column types** NusaDB accepts: `int`, `bigint`, `smallint`, `boolean`, `real`,
  `double precision`, `numeric(p,s)`, `text` (also for `@Lob String`), `date`, `time`, `timestamp`,
  `varbinary` (also for `@Lob byte[]`), and `uuid` for `java.util.UUID`.
- **Ids**: every `@GeneratedValue` strategy. `IDENTITY` is a `GENERATED BY DEFAULT AS IDENTITY`
  column; `SEQUENCE` and `AUTO` use native sequences, pooled when `allocationSize > 1`; `TABLE` and
  `uuid2` work as well.
- **Names** the server reserves (a column named `key`, `index` or `interval`, a table named
  `replace`) are quoted, so such entities need no `@Column(name = "\"key\"")`.
- **HQL functions** under the server's names: `locate` (as `position`), `trim` (with the
  character spelled out), `str`, `current_date`, `current_timestamp`, `concat`, and string, numeric
  and date functions such as `lpad`, `replace`, `round`, `trunc`, `date_trunc`.
- **Pagination** (`setMaxResults` / `setFirstResult`) as a constant `LIMIT`/`OFFSET`.
- **Locks**: `PESSIMISTIC_WRITE` as `FOR UPDATE`, with `NOWAIT` for a lock timeout of 0 and
  `SKIP LOCKED` for -2. Deadlocks, `NOWAIT` failures and statement timeouts become Hibernate's typed
  exceptions; integrity errors carry the constraint name.

Spring Data's derived `Containing` / `StartingWith` / `Like` queries bind the `LIKE` escape
character as a parameter under Hibernate 5; the driver writes it into the statement, since the
server takes only a literal there.

## Build & test

From the repository root (see the [root README](../README.md#build--test) for how the
integration tests find a server):

```bash
mvn verify -Pit -pl hibernate5 -am
```

`HibernateIT` exercises schema export, persist/load, update, a query with a row limit, delete, and
transaction rollback; `DialectFeaturesIT` the id generators, the `uuid` column, reserved names and
the HQL functions.
